# ZTools Documentation

Open-source documentation for **[ZTools](https://ztools.zaions.com)** — a free, browser-only collection of 520+ developer & creator tools. Built with [Docusaurus 3](https://docusaurus.io).

🌐 **Live site:** [ztools-docs.zaions.com](https://ztools-docs.zaions.com)
🛠 **App:** [ztools.zaions.com](https://ztools.zaions.com)
📦 **App on Play Store:** [com.zaions.ztools](https://play.google.com/store/apps/details?id=com.zaions.ztools)

---

## What this repo is

A Docusaurus site documenting every ZTools tool with use cases, examples, FAQs, and tips. Per-tool MDX pages are auto-generated from the ZTools app's content data files — single source of truth.

## What this repo is NOT

The ZTools app itself is in a separate (currently private) repo. This is **just the docs**.

---

## Run locally

```bash
yarn install
yarn generate:tools   # Read content from ../ztools/, emit MDX into docs/tools/
yarn build            # Production build into build/
yarn start            # Local dev server (we typically skip this — author runs ./build serving)
```

> The generator (`scripts/generate-tool-pages.ts`) expects the **ZTools app repo** to be at `../ztools/` relative to this repo. If you're cloning standalone, the generator falls back to skipping unknown tools.

## Add a new tool to the docs

The docs roll out 15-20 tools per batch to keep quality high. To add a tool:

1. Make sure the tool has rich content in the ZTools app: `../ztools/src/data/toolContent/batchNN.ts`
2. Add the tool's `id` to `TOOLS_TO_PUBLISH` in `scripts/generate-tool-pages.ts`
3. Run `yarn generate:tools && yarn build` to verify
4. Commit + push — GitHub Actions deploys to `ztools-docs.zaions.com`

## Deployment

**Hosting:** GitHub Pages with custom domain `ztools-docs.zaions.com`.
**CI:** GitHub Actions — `.github/workflows/deploy.yml` runs on push to `main`.

The `static/CNAME` file pins the custom domain. DNS: CNAME `ztools-docs` → `aoneahsan.github.io`.

- ✅ AI crawlers allowed in `robots.txt` (GPTBot, ChatGPT-User, ClaudeBot, anthropic-ai, PerplexityBot, Google-Extended, Bingbot, Applebot, CCBot)
