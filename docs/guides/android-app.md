# Install the ZTools Android app

ZTools ships as a native Android app — the same tools as the web app, wrapped with Capacitor so they run in a standalone app window.

## Install from Google Play

**[ZTools on Google Play ↗](https://play.google.com/store/apps/details?id=com.zaions.ztools)**

Package id: `com.zaions.ztools`.

## What you get

- The full ZTools tool set in an app-like experience, with a home-screen icon.
- The same browser-only processing — for the free tools, your input stays on the device.
- Optional Google sign-in for favorites, history, and cross-device sync.

## iOS

An iOS build is ready in code but not yet published — it's waiting on an Apple Developer account. Until then, iPhone and iPad users can use the web app at [ztools.zaions.com](https://ztools.zaions.com), or add it to the home screen (see [Install ZTools as an app](/docs/guides/install-as-app)).
