# Install the ZTools browser extension

The ZTools extension puts quick tool access one click away from any tab — no need to open the full site first.

## Chrome, Edge, Brave, and other Chromium browsers

Install from the Chrome Web Store:

**[ZTools on the Chrome Web Store ↗](https://chromewebstore.google.com/detail/ztools-300+-utility-tools/olkionpeobbpgmlfigafppbkniomelle)**

The same package installs on any Chromium-based browser (Edge, Brave, Opera, Vivaldi) via the Chrome Web Store.

## Firefox

A Firefox build is maintained alongside the Chrome one. If it isn't yet listed for your browser, use the web app at [ztools.zaions.com](https://ztools.zaions.com) — it works identically in Firefox.

## What it does

- Opens the tools you use most from the toolbar popup.
- Sends you straight to a tool's page on the app.

## Privacy

The extension opens ZTools tool pages. Processing depends on the tool you choose: many tasks run in your browser, while AI and some other tools send input to a server or provider. Read the app's [privacy policy](https://ztools.zaions.com/privacy-policy) before submitting sensitive input.
