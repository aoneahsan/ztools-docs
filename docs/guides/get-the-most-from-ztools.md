# Get the most out of ZTools

The [Getting Started](/docs/getting-started) page covers the basics. This guide is the shortcut list for working faster once you know your way around.

## Find a tool in seconds

- **Search** — use the app search box to find a tool by name or task, then choose a result.
- **Direct link** — open a tool from its docs page or the app catalog and bookmark that link. A tool's app route isn't always its ID.
- **Browse by category** — see [Browse tools by category](/docs/guides/browse-by-category).

## When do I need to sign in?

Many tools can be used without an account. Sign in for Growth Suite and account features such as favorites. Signed-in favorites and some account preferences can sync across devices; other work may stay on the device or be handled by a separate service.

Processing depends on the action. Many tasks run in your browser; AI and some other tools send input to a server or provider. Read the [ZTools privacy policy](https://ztools.zaions.com/privacy-policy) before submitting sensitive input.

## Make it yours

The palette icon in the header opens the theme customizer: appearance (light / dark / system), accent color, font size, scaling, border radius, and panel background. Appearance preferences persist on your device. Some account preferences can sync when you're signed in.

## Share a result

Some tools offer a Share action. When one is available, review what that tool includes before you send the link or result.
