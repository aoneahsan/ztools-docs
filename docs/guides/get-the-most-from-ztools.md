# Get the most out of ZTools

The [Getting Started](/docs/getting-started) page covers the basics. This guide is the shortcut list for working faster once you know your way around.

## Find a tool in seconds

- **Search** — the search box (top of the app, and on this docs site) fuzzy-matches tool name, description, and category. Start typing and hit Enter on the first result.
- **Direct URL** — every tool has a stable address: `ztools.zaions.com/<tool-id>`. Bookmark the ones you use daily.
- **Browse by category** — see [Browse tools by category](/docs/guides/browse-by-category).

## Sign in only when it pays off

ZTools works fully signed-out. Signing in (Google) adds three things:

- **Favorites** — pin the tools you reach for most.
- **History** — your last inputs, per tool, so you can pick up where you left off.
- **Cloud sync** — favorites and preferences follow you across devices.

Your tool inputs are never sent to a server for the free browser-only tools — sign-in only syncs favorites and preferences.

## Make it yours

The palette icon in the header opens the theme customizer: appearance (light / dark / system), accent color, font size, scaling, border radius, and panel background. Preferences persist on your device; signed-in users get cross-device sync.

## Share a result

Most tools have a Share button that copies a deep link (when the input fits in a URL) or a shareable image for visual tools. On mobile it uses the native share sheet.
