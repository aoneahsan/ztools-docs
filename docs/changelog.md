# Changelog

## 0.1.0 — 2026-05-06

**Initial release.**

- Documentation site scaffolded with Docusaurus 3
- First wave: top 20 highest-demand tools documented (foundation tools — JSON formatter, password generator, base64, QR generator, etc.)
- Per-tool MDX pages auto-generated from the ZTools app's content data files
- Full SEO setup: sitemap, RSS, JSON-LD, OpenGraph, Twitter Cards
- Deployed to `ztools-docs.zaions.com` via GitHub Pages
- Source: [github.com/aoneahsan/ztools-docs](https://github.com/aoneahsan/ztools-docs)

**Next batch (planned):**
- Add 15-20 more tools (text + image categories)
- First long-form how-to guides
- Algolia DocSearch integration for site-wide search
