# audio-cutter

An audio cutter is a tool for trimming the start and end of an audio file, removing dead air, mistakes, or unwanted sections, producing a cleaner clip ready for sharing or further editing. The ZTools Audio Cutter runs entirely in the browser using the Web Audio API, displays a visual waveform, lets you drag handles to set start / end markers, supports preview before export, and outputs MP3 / WAV / OGG directly to your device — no server upload required for files up to several minutes long.

## Use cases

### Podcast clip extraction

Pull a 60-second highlight from a 45-minute podcast for social-media promo. Visual waveform makes finding the right section fast.

### Ringtone creation

Trim a song down to a 30-second loop for a phone ringtone. iOS / Android both accept M4A / MP3 ringtones at this length.

### Voice-memo cleanup

Recorded a 10-minute voice memo but only the last 2 minutes matter. Cut the dead intro and silence, share a tight clip.

### Audiobook / lecture excerpts

Pull a quotable passage from an hour-long audiobook for a presentation, blog post, or share with a colleague.

## How it works

1. **Upload an audio file** — Drag-and-drop or file picker. Common formats supported: MP3, WAV, OGG, M4A, FLAC.
2. **Wait for waveform to render** — Audio decodes in-browser; waveform draws across the timeline. Time-stamps shown beneath.
3. **Drag start and end handles** — Pinch the segment to keep. Preview button plays only the selected region so you can verify.
4. **Pick output format** — Same as input (re-encoding only the trimmed segment) or convert at export. MP3 / WAV / OGG common targets.
5. **Download** — Tool exports the trimmed segment as a new file. Original is untouched in your filesystem.

## Frequently asked questions

<details>
<summary>**How precise can I cut?**</summary>

Sub-second precision. The waveform renders to ~10 ms resolution; the drag handles snap finely. For frame-accurate cuts, zoom in on the waveform.

</details>

<details>
<summary>**Will the file lose quality?**</summary>

If you cut and export to the same format and bitrate, lossy formats (MP3) re-encode and lose some quality. Cut to WAV for lossless, or accept minor degradation for lossy targets.

</details>

<details>
<summary>**How big a file can I cut?**</summary>

Browser-memory limits matter. Up to ~30-minute MP3 (a few hundred MB decoded) is fine on modern laptops. Larger files may need desktop tools (Audacity).

</details>

<details>
<summary>**Can I cut multiple segments and join them?**</summary>

For multi-segment cuts, use the audio-joiner tool after producing individual clips. Or use desktop DAW software for complex multi-cut workflows.

</details>

<details>
<summary>**Is my audio uploaded?**</summary>

No — entirely client-side. File never leaves your device. Privacy by design.

</details>

<details>
<summary>**What about fade-in / fade-out?**</summary>

Basic fade controls included. For complex envelopes (multi-point fades, EQ), step up to a DAW like Audacity (free) or Reaper.

</details>

## Tips

- Always preview the trim before downloading — small misjudgments cost re-export.
- Add a 0.1-0.3 second fade-in / fade-out on cut edges to avoid clicks; abrupt cuts pop audibly.
- For voice clips, leave 0.2 seconds of silence at start so playback hardware does not chew the first phoneme.
- Cut to WAV during multi-step editing; convert to MP3 only for final delivery to avoid generation loss.
- Save the cut points (start / end timestamps) in a doc — easier to re-cut later than to re-find the section.
