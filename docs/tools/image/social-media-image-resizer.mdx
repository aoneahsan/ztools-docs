# Social Media Image Resizer

A social media image resizer takes one source image and produces multiple sized variants matching each platform's exact spec — Instagram feed (1080×1080), IG portrait (1080×1350), IG story/reel (1080×1920), Facebook post (1200×630), Twitter/X header (1500×500), LinkedIn cover (1584×396), YouTube thumbnail (1280×720), TikTok video poster (1080×1920), Pinterest pin (1000×1500), and 20+ more. The ZTools Social Media Image Resizer outputs all variants in a single ZIP with platform-named files (`facebook-post.png`, `linkedin-cover.png`, etc.) — saving the manual resize-export cycle for each platform.

## How it works

1. **Upload source image** — Highest-resolution version available (4K+ ideal for downscale-only).
2. **Pick target platforms** — Instagram (post / portrait / story), Facebook (post / cover / event), Twitter/X (post / header), LinkedIn (post / cover / profile-pic), YouTube (thumbnail / banner), TikTok (poster), Pinterest (pin / board cover), Snapchat, Reddit.
3. **Pick crop strategy** — Center crop (default), top-aligned, smart crop (face/subject detection), or letterbox (no crop, add bars).
4. **Process** — Each variant resized via Canvas with high-quality bicubic downscale.
5. **Download ZIP** — All variants in one ZIP with platform-named files.

## Frequently asked questions

<details>
<summary>**Will the crop look right for every platform?**</summary>

Center-crop works 80% of the time. For images with off-center subjects, use smart-crop (face-aware) or top-aligned. Test on the actual platforms before scheduling a campaign.

</details>

<details>
<summary>**Can I add per-platform overlays?**</summary>

Not in this tool — pure resize. For platform-specific overlays (e.g. "watch on YouTube" play button), use a design tool after.

</details>

<details>
<summary>**Does it preserve quality?**</summary>

Yes — bicubic downscale with anti-aliasing. Quality matches Photoshop's "Preserve Details" output.

</details>

<details>
<summary>**Are the dimensions current as of 2026?**</summary>

Yes — platform specs change occasionally; this tool maintains a 2026-current reference. Check platform docs for updates if shipping production assets.

</details>

<details>
<summary>**Will it work for vertical Reels / TikToks?**</summary>

Yes — 1080×1920 (9:16) is supported. Note: for video, use the source video's native aspect ratio; this tool handles still cover/poster images.

</details>

<details>
<summary>**Why does my logo look pixelated after resize?**</summary>

You're likely upscaling. Always start with the highest-res source available; downscaling preserves quality, upscaling doesn't.

</details>

## Tips

- Always start with 4K+ source resolution; downscaling preserves quality, upscaling never does.
- Smart-crop (face-aware) for portraits; center-crop for products and graphics.
- For social, optimize the file with the smart-image-optimizer after resizing — saves 50–80% bandwidth.
- Some platforms preview at one size and display at another (Twitter card 1200×630 displays at various sizes). Match the spec, the platform handles the rest.
- Bookmark this tool — most asset workflows revisit it weekly.
