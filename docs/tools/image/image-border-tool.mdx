# Image Border Tool

An image border tool adds a decorative or functional border around a photo — solid color, gradient, polaroid (thick white frame with caption space), film-strip, vintage-rounded, or shadow-box. Used for Instagram-feed framing, photo prints, gallery walls, and protecting subject edges from being trimmed by Instagram's feed crop. The ZTools Image Border Tool runs entirely in the browser using Canvas, with adjustable width / color / radius / opacity per side, plus 12+ preset frame styles (polaroid, film, vintage, shadow-box, gradient, multi-layer).

## Use cases

### Instagram feed framing

Add a 4–8% white border around square photos to create a "polaroid" feel. Stops the eye from running off the edge of the photo into the next post.

### Print preparation

Prints framed by physical mats need a virtual margin so important content isn't covered by the mat. Add 5–10% white border before sending to print lab.

### Multi-photo collages

Borders separate photos in a collage. Without borders, adjacent photos blur into each other; with borders, each photo is its own framed unit.

### Subject pop

Dark border on a light photo (or vice versa) intensifies the subject. Shadow-box borders add depth without ink.

## How it works

1. **Upload image** — JPG / PNG / WebP. Any dimensions.
2. **Pick border style** — Solid, gradient, polaroid, film-strip, vintage, shadow-box, multi-layer, dashed, decorative.
3. **Set width** — Per side or uniform. Common: 2–10% of shortest edge for proportional look.
4. **Set color / gradient** — Hex picker or gradient stops. Black/white most common; brand color for marketing photos.
5. **Optional caption** — For polaroid style — bottom margin includes editable caption text.
6. **Export** — PNG (preserves any transparency in border) or JPG (smaller).

## Frequently asked questions

<details>
<summary>**Will the border affect file size much?**</summary>

Borders add ~5–15% to file size depending on width and color (solid colors compress well; gradients less). For web use, this is negligible.

</details>

<details>
<summary>**Can I add a drop shadow?**</summary>

Yes — the shadow-box style includes adjustable shadow blur, offset, and color.

</details>

<details>
<summary>**How thick should my border be?**</summary>

Web/social: 2–6% of shortest edge. Print: 5–10%. Polaroid style: 8–12% with extra space at bottom for caption.

</details>

<details>
<summary>**Does the border get cropped on Instagram?**</summary>

Instagram crops feed photos to 1:1 (or 4:5 for portrait). Borders within those ratios are preserved.

</details>

<details>
<summary>**Can I batch-apply the same border?**</summary>

Yes — upload multiple files, settings apply uniformly. Useful for product photo galleries with consistent framing.

</details>

<details>
<summary>**Is the original modified?**</summary>

No — borders are added to a Canvas copy. Original file untouched on your device.

</details>

## Tips

- White border on dark photos / dark border on light photos — pick contrast for visibility.
- For social, 4–6% border is the sweet spot; thicker feels old-fashioned.
- Polaroid borders work best on portrait/square photos, not panoramas.
- Use the brand color as a thin (1–2%) outer accent border for marketing imagery.
- For print, account for the physical mat width — subtract that from your virtual border.
