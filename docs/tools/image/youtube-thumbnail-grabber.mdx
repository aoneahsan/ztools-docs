# youtube-thumbnail-grabber

A YouTube thumbnail grabber fetches the public thumbnail image of any YouTube video at every resolution YouTube serves — from 120x90 default through 480x360 medium, 640x480 standard, up to 1280x720 maxres — using only the video ID, so you can preview the thumbnail in design comps, archive a reference, or analyse competitors' thumbnail strategies without screen-grabbing. The ZTools YouTube Thumbnail Grabber accepts any YouTube URL form (watch, share, shortened, embedded, Shorts), extracts the video ID, and shows all available resolutions side-by-side with one-click downloads — all without YouTube API keys, accounts, or rate limits.

## How it works

1. **Paste a YouTube URL** — Any form — youtube.com/watch?v=, youtu.be/, youtube.com/shorts/, youtube.com/embed/, mobile m.youtube.com.
2. **Extract the video ID** — 11-character ID parsed from the URL. Manual ID input is also supported.
3. **Fetch all resolution variants** — default (120x90), mqdefault (320x180), hqdefault (480x360), sddefault (640x480), maxresdefault (1280x720). Not all videos have maxres.
4. **Preview side-by-side** — Inspect each resolution before download. Filenames include the video ID and resolution label.
5. **Download individually or all at once** — Single image or ZIP of all available variants.

## Frequently asked questions

<details>
<summary>**Is downloading thumbnails legal?**</summary>

For personal reference, archival, and editorial commentary, generally yes (fair use). For commercial reuse, get permission from the channel — copyright belongs to the uploader.

</details>

<details>
<summary>**Why is maxres unavailable for some videos?**</summary>

Maxres is generated by YouTube only when the source is high enough resolution. Older videos and mobile uploads sometimes top out at hqdefault.

</details>

<details>
<summary>**Does it work for private or unlisted videos?**</summary>

Unlisted: yes if you have the URL. Private: no — the thumbnail endpoint requires the video to be publicly fetchable.

</details>

<details>
<summary>**Can I grab a YouTube live-stream's thumbnail?**</summary>

Yes — same endpoints. Note the thumbnail may change as the stream progresses.

</details>

<details>
<summary>**Does it use the YouTube API?**</summary>

No. The thumbnail URLs are static patterns based on the video ID; no API key, no quota.

</details>

<details>
<summary>**Is there a batch mode for many URLs?**</summary>

Yes — paste a list of URLs (one per line) and the grabber returns a ZIP of all maxres thumbnails.

</details>

- Always download maxres if available — it scales down cleanly to any size.
