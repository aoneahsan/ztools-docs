A logo maker assembles a simple brand mark from a chosen icon + brand name + optional tagline, with adjustable typography, color, and layout — useful for early-stage startups, side projects, blogs, and personal brands that need a logo before budget allows hiring a designer. The ZTools Logo Maker runs entirely in the browser, draws SVG (vector, infinitely scalable, small file size), offers hundreds of icon options across categories, exports SVG / PNG, and stores no design data on any server.

## How it works

1. **Pick an icon** — Browse categorised icons (tech, business, nature, abstract). Each is SVG so it scales cleanly.
2. **Add brand name** — Type your brand name; pick font (sans-serif modern, serif classic, display for character). 5-10 fonts curated.
3. **Add tagline (optional)** — Smaller subtext below the brand name. 3-5 word tagline summarising brand promise.
4. **Pick layout** — Horizontal (icon left, text right), stacked (icon top, text below), icon-only (mark for square avatars).
5. **Customise color + spacing** — Pick brand color from palette or hex. Adjust spacing between icon and text. Live preview.

## Frequently asked questions

<details>
<summary>**Is this a real logo or a placeholder?**</summary>

For MVPs, side projects, and early-stage brands: real enough. Mature brands eventually invest in custom design — but generator-made logos serve well in the meantime.

</details>

<details>
<summary>**Why SVG?**</summary>

Scales infinitely without quality loss; smaller file size than PNG at large dimensions; editable in Inkscape / Figma / browser. The format-of-choice for web logos.

</details>

<details>
<summary>**Are the icons license-free for commercial use?**</summary>

Bundled icons use permissive licenses (CC0 or MIT-style). Always check the license before commercial use; rules vary by source.

</details>

<details>
<summary>**Should I trademark a generator-made logo?**</summary>

Trademarks protect distinctive branding. Generator logos using common icons are harder to defend as distinctive. For trademark protection, commission custom design.

</details>

<details>
<summary>**Can I export at custom sizes?**</summary>

SVG is infinitely scalable. PNG export at any size (256px, 512px, 1024px, 2048px) for non-vector destinations.

</details>

<details>
<summary>**Is anything uploaded?**</summary>

No — entirely client-side. Your brand stays private.

</details>

## Tips

- Test the logo at small sizes (32px favicon, 48px social profile) — many logos look fine at large but blur at small.
- Keep it simple. The strongest logos are recognisable at a glance. Complex multi-element marks lose impact.
- Match font choice to brand voice. Serif = traditional / authoritative. Sans-serif = modern / approachable. Display = playful / character.
- Use 1-2 colors maximum. More colors = more printing cost + harder to remember.
- Save SVG as the master; export PNG / JPG for specific destinations as needed.
