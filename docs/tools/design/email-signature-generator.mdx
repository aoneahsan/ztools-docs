## How it works

1. **Enter contact info** — Name, title, company, email, phone, website, social URLs (LinkedIn, Twitter, GitHub).
2. **Pick layout** — Vertical (info stacked) or horizontal (logo left, info right). Vertical wins for narrow viewports; horizontal for branded look.
3. **Customise styling** — Brand color, font, separator style, logo upload (uses a hosted URL or base64 inline).
4. **Generate HTML** — Tool produces inline-CSS HTML block. Inline styles are the only reliable way to style email — most clients strip &lt;style&gt; blocks.
5. **Copy + paste** — Copy as rich content into Gmail (Settings → Signature) or as raw HTML into Outlook (signature editor source).

## Frequently asked questions

<details>
<summary>**Why are inline styles needed?**</summary>

Email clients strip or reject &lt;style&gt; blocks; inline styles attached to each element survive. Generator outputs all-inline-CSS HTML for compatibility.

</details>

<details>
<summary>**Should I use an image-based or text-based signature?**</summary>

Text-based signatures are bulletproof (every client renders text). Image-based look more polished but break when recipients block images. Best practice: text + small inline logo.

</details>

<details>
<summary>**How do I add the signature to Gmail / Outlook?**</summary>

Gmail: Settings → General → Signature → paste rich-content. Outlook: File → Options → Mail → Signatures → paste HTML source. Apple Mail: Preferences → Signatures.

</details>

<details>
<summary>**Will the signature break on mobile?**</summary>

Generator uses simple table-based layouts (the only reliable cross-client format). Mobile clients render correctly. Test on iPhone / Android Gmail.

</details>

<details>
<summary>**Can I include tracking?**</summary>

Possible (UTM-tagged links, tracking pixels) but creepy. Most professional contexts avoid pixel tracking — recipients notice and resent.

</details>

<details>
<summary>**Is the input uploaded?**</summary>

No — client-side only. Your contact details stay in the browser.

</details>

## Tips

- Keep signatures under 5-6 lines. Long signatures push email content below the fold.
- Test in your actual email client before rolling out — different versions of Outlook render slightly differently.
- Avoid web fonts; use system fallbacks (Arial, Helvetica, sans-serif). Web fonts often fail in email.
- Update signatures quarterly — stale phone numbers, dead social links signal carelessness.
- For company-wide signatures, distribute the HTML + setup instructions; centralised email-management tools can also enforce consistency.
