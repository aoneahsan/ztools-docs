# Poster Maker

A poster maker produces standard-sized printable posters — A4 (210×297mm), A3, A2, US Letter (8.5×11"), tabloid (11×17") — with bold typography and imagery, useful for events, recruitment, classroom decoration, retail promotions, and bulletin-board notices. The ZTools Poster Maker runs entirely in the browser, supports common print sizes with optional bleed, multi-layer composition (background + image + text + shape), and exports print-ready PDF (300 DPI) or PNG.

## Use cases

### Event promotion

Concert, lecture, meetup, sale: poster with date / location / call-to-action. Hand to print shop or DIY print at home / office.

### Classroom / educational

Teachers print rules-of-conduct posters, vocabulary references, scientific diagrams. Persistent visual aids beat one-off slide deck.

### Retail / shop display

Window or in-store promo: "20% Off This Week" or "New Collection". Generator outputs print-ready files.

### Internal communications

Office bulletin: safety notice, new procedure, town hall announcement. Print 1-2 copies for high-traffic walls.

## How it works

1. **Pick size** — A4 / A3 / A2 / A1 (metric) or US Letter / Tabloid / Poster (US). Each has standard-print orientation (portrait / landscape).
2. **Add background** — Solid color, gradient, full-bleed image. For maximum impact, fill the entire poster with the dominant element.
3. **Add headline** — Top-third placement, 100-200pt font for A4; scale up proportionally for larger sizes. Bold sans-serif typically outperforms decorative fonts at distance.
4. **Add supporting info** — Date, location, contact. Mid-poster or bottom; smaller font (40-60pt). Hierarchy: headline → supporting → fine print.
5. **Export print-ready PDF** — 300 DPI, embedded fonts, optional bleed (3mm). Submit to printer or DIY print on heavy stock.

## Frequently asked questions

<details>
<summary>**What size for which use?**</summary>

A4: small notice, classroom, single-sheet event. A3: bulletin board, store window. A2 / A1: street poster, store front. US Letter ≈ A4. Tabloid ≈ A3.

</details>

<details>
<summary>**Can I print at home?**</summary>

A4 / Letter: most home / office printers. A3 / Tabloid: needs A3-capable printer (some home printers, most office printers). A2+: print shop only or split across multiple sheets.

</details>

<details>
<summary>**What's the best font size?**</summary>

Headline: read from 3 metres = ~100pt at A3; from 5 metres = ~150pt. Supporting info: 40-60pt at A3. For very large posters (A2+), scale up everything proportionally.

</details>

<details>
<summary>**Color: CMYK vs RGB?**</summary>

Print = CMYK. Bright colors on screen (especially deep blues, vivid greens) can shift on print. For high-stakes color matching, request a printer proof.

</details>

<details>
<summary>**Is anything uploaded?**</summary>

No — Canvas / PDF generation runs entirely in the browser.

</details>

<details>
<summary>**How do I make a poster eye-catching?**</summary>

Big bold headline, single dominant image / color, tight info hierarchy, white space. Avoid clutter; one focal point beats five.

</details>

## Tips

- Big headline. Small body text loses to crowd noise; big headline cuts through.
- High contrast: dark text on light background or vice versa. Mid-tone-on-mid-tone is unreadable from distance.
- Print one A4 first to test legibility — if it works at A4, it works enlarged. The reverse is not true.
- Use 1-2 fonts and 2-3 colors. Posters fail when busy.
- Place call-to-action (date, location, URL, QR) in lower third — eyes scan top-down.
