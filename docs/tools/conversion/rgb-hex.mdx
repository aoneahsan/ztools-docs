# RGB/Hex Converter

An RGB to hex converter translates color values between the three common formats — RGB triplets like rgb(255, 136, 0), hex codes like #FF8800, and HSL like hsl(32, 100%, 50%) — used by CSS, design tools, and image-processing pipelines. ## Frequently asked questions

<details>
<summary>**How does hex relate to RGB?**</summary>

Each pair of hex digits is one channel: red, green, blue. #FF8800 = R:0xFF (255), G:0x88 (136), B:0x00 (0). Use the Number Base Converter for the hex math.

</details>

<details>
<summary>**What's the difference between #F80 and #FF8800?**</summary>

CSS short hex (#F80) expands to long form (#FF8800) by repeating each digit. So #F80 = #FF8800 = same color. Short form is just shorter to type.

</details>

<details>
<summary>**When should I use HSL instead of RGB?**</summary>

HSL is friendlier for human reasoning: hue is what color (0-360°), saturation is how vivid (0-100%), lightness is how bright (0-100%). To make a color "more red", change hue. RGB requires changing R and adjusting G/B inversely.

</details>

<details>
<summary>**How does alpha (transparency) work?**</summary>

Alpha 1.0 (or 255) = fully opaque. Alpha 0 = fully transparent. In hex 8-digit form, the last two digits are alpha: #FF8800CC has alpha 0xCC = 204 ≈ 80% opaque.

</details>

<details>
<summary>**Are CSS named colors universal?**</summary>

The CSS Level 3 specification defines 140+ named colors (red, blue, dodgerblue, etc.). Modern browsers support them all. For brand-specific colors, use exact hex/RGB.

</details>

## Tips

- For brand colors, store the exact hex — don't round to a nearby named color.
- When designing dark/light theme variants, work in HSL: change lightness, keep hue/saturation.
- Always specify color in only one format per file — mixing causes confusion in code reviews.
- Alpha is the last channel — RGBA and 8-digit hex append it; RGB and 6-digit hex omit it.
