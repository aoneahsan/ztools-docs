# Convert Decimal to ASCII

Decimal to ASCII reverses the encoding: 65 → A, 97 → a, 32 → space. Useful for decoding character-code arrays, recovering text from C-style int arrays, and reading hex-dump-derived sequences. The ZTools Decimal to ASCII converter accepts any whitespace / comma-separated decimal list and outputs the resulting text, with warnings for out-of-range or non-printable codes.

<ToolCTA toolId="decimal-to-ascii" toolName="Convert Decimal to ASCII" />

## Use cases

### Decode a char array

C array \{72, 101, 108, 108, 111\} → "Hello". Useful for reading firmware dumps.

### Read a manually-typed hex/decimal sequence

Forensics or CTF: hex/decimal numbers; convert to readable text.

### Inspect serialised data

Some binary formats use ASCII-decimal length prefixes — decode to verify.

## How it works

1. **Paste decimal codes** — Comma, space, or newline-separated. Tool parses each as integer.
2. **Validate** — Codes 0-127 are pure ASCII. 128-255 extended. Above 255 (Unicode) toggles to UTF-8 mode.
3. **Convert** — String.fromCharCode per code. Output assembled.
4. **Display** — Resulting text. Non-printable codes shown as escape sequences (\\n, \\t) or control symbols.

## Frequently asked questions

<details>
<summary>**What if a code is out of range?**</summary>

0-127 is pure ASCII. 128-255 is locale-dependent. Above 255 is Unicode (toggle UTF-16 / UTF-32 mode).

</details>

<details>
<summary>**Non-printable codes?**</summary>

Codes 0-31 are control characters. Tool shows them as \\n, \\t, etc., or special symbols (NUL, SOH).

</details>

<details>
<summary>**Privacy?**</summary>

All in browser.

</details>

## Tips

- For pure ASCII text, codes stay 32-126 (printable). Anything else hints at non-ASCII or control characters.
- For roundtrip verification, convert text → decimal → text and confirm match.
