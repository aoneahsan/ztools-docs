# All ZTools

ZTools is a free, browser-only collection of **520+ developer & creator tools**. Every tool listed here is documented with use cases, examples, and FAQs.

This index is the **first wave** — top 20 highest-demand tools. The rest land in subsequent batches; track progress on the [GitHub repo](https://github.com/aoneahsan-ztools-docs).

## Conversion

- [**base64**](/docs/tools/conversion/base64) — Encode or decode data in Base64 format instantly.
- [**url-encoder**](/docs/tools/conversion/url-encoder) — Encode and decode URLs and query parameters.
- [**markdown-html**](/docs/tools/conversion/markdown-html) — Convert Markdown to HTML and vice versa.

## Data

- [**json-formatter**](/docs/tools/data/json-formatter) — Format and beautify JSON data.
- [**json-minifier**](/docs/tools/data/json-minifier) — Minify JSON by removing whitespace.

## Encoding

- [**qr-generator**](/docs/tools/encoding/qr-generator) — Generate QR codes from text or URLs.
- [**hash-generator**](/docs/tools/encoding/hash-generator) — Generate MD5, SHA-1, SHA-256 hashes.
- [**jwt-decoder**](/docs/tools/encoding/jwt-decoder) — Decode and inspect JSON Web Tokens.

## Generator

- [**password-generator**](/docs/tools/generator/password-generator) — Generate strong, random passwords.
- [**uuid-generator**](/docs/tools/generator/uuid-generator) — Generate unique identifiers (UUID/GUID).
- [**cron-expression**](/docs/tools/generator/cron-expression) — Build and validate cron expressions with visual builder and human-readable descriptions.

## Image

- [**color-picker**](/docs/tools/image/color-picker) — Pick colors from images.
- [**image-compressor**](/docs/tools/image/image-compressor) — Reduce image file size.
- [**image-resizer**](/docs/tools/image/image-resizer) — Resize images to specific dimensions.
- [**favicon-generator**](/docs/tools/image/favicon-generator) — Generate all favicon sizes for web, iOS, and Android from a single image. Download as ZIP with HTML snippets and web manifest.

## Pdf

- [**merge-pdf**](/docs/tools/pdf/merge-pdf) — Combine multiple PDF files into one document.

## Text

- [**lorem-ipsum**](/docs/tools/text/lorem-ipsum) — Generate placeholder text for your designs and mockups quickly.
- [**word-counter**](/docs/tools/text/word-counter) — Count words, characters, sentences, and analyze your text instantly.

## Utility

- [**regex-tester**](/docs/tools/utility/regex-tester) — Test and debug regular expressions with live matching.
- [**diff-checker**](/docs/tools/utility/diff-checker) — Compare text and code differences.
