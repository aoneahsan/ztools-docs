# css-text-glitch-generator

A glitch effect makes text look like it's breaking up on a CRT or a corrupted display — RGB channel split, horizontal jitter, scanline overlays, occasional jumps. The ZTools CSS Text Glitch Generator produces the visual using pure CSS pseudo-elements and keyframe animations — no JavaScript, no images, no frameworks. Pick colour offsets, intensity, animation duration; copy the result and paste anywhere CSS works.

## How it works

1. **Pick the text** — Type the text to glitch. Generator handles the duplicated layers automatically.
2. **Configure intensity** — Channel offset (1-5 px), animation speed (0.5-3 s), jitter amount, scanline overlay opacity.
3. **Pick colours** — Default cyan + magenta (most legible RGB split). Customise per channel for brand-tinted glitches.
4. **Copy HTML + CSS** — Output: a single element with data-attribute carrying the text + ~40 lines of CSS using ::before/::after for the duplicated layers.

## Frequently asked questions

<details>
<summary>**Will this hurt accessibility?**</summary>

Yes if used heavily — the animated jitter can trigger motion sensitivity. Always wrap the effect in @media (prefers-reduced-motion: reduce) and disable animation for those users.

</details>

<details>
<summary>**Is the text searchable / readable to crawlers?**</summary>

Yes — text lives in the DOM. The pseudo-element layers pull from data-text="..." attribute or a ::before \{ content: attr(data-text) \} pattern. Crawlers see plain text.

</details>

<details>
<summary>**Does it work in all browsers?**</summary>

Modern browsers (Chrome, Firefox, Safari, Edge). IE11 not supported (no relevant). Falls back to plain text gracefully.

</details>

<details>
<summary>**Privacy?**</summary>

All generation in browser.

</details>

## Tips

- Always honour prefers-reduced-motion — disable animation; static RGB-split layers still look interesting without the motion.
- Use sparingly — one hero element, not every heading. The effect loses impact when overused.
- Pair with a monospace or display font — generic sans-serif looks weak under glitch.
- For dark backgrounds, RGB split reads as cyan + magenta on white text. For light backgrounds, invert: red + blue on dark text.
