# Safe File Name Generator

A safe file name is one that survives every filesystem and URL it might pass through — Windows (no &lt;&gt;:"|?* or reserved names like CON, NUL), macOS (no colons), Linux (no slashes / null bytes), S3 (no spaces if you want clean URLs), URLs (no spaces or non-ASCII without encoding). The ZTools Safe File Name Generator takes a free-form string and produces a file name that's legal everywhere. Configurable: lowercase or preserve case, replace spaces with - or _, transliterate accents (café → cafe), keep extension, drop or trim length, prepend a date.

## Use cases

### Sanitize user-uploaded file names

A user uploads "Résumé - Final (v3) &lt;draft&gt;.pdf". Save as resume-final-v3-draft.pdf to avoid filesystem and URL trouble.

### Generate IDs for a static file storage

Each blog post needs a permanent slug-like name. Generator turns the title into a stable, lowercase, dash-separated name.

### Build batch-rename rules

Apply a consistent naming convention across 1000 files (date prefix + slug). Generator outputs the new names; rename script applies them.

### Prevent filename collisions

Two uploads named "Document.pdf" — the second overwrites the first. Add a date / hash prefix to disambiguate.

## Frequently asked questions

<details>
<summary>**What characters are illegal where?**</summary>

Windows: &lt; &gt; : " / \\ | ? * + reserved names (CON, PRN, AUX, NUL, COM1-9, LPT1-9). macOS: : (slash internally, colon at API level). Linux: / and null. URLs: spaces and most non-ASCII unless encoded.

</details>

<details>
<summary>**Why transliterate accents?**</summary>

Some platforms (older S3, some Linux fs without UTF-8 locale) mangle accented characters. Transliteration (café → cafe) prevents that. Skip if your target supports UTF-8 fully.

</details>

<details>
<summary>**Is the result reversible?**</summary>

No — once "café" becomes "cafe", you can't recover the accent. Store the original in a database column if you need it for display.

</details>

<details>
<summary>**What about emoji in file names?**</summary>

Most filesystems handle them since UTF-8 became standard. Generator can preserve or strip — toggle per use case.

</details>

<details>
<summary>**Privacy?**</summary>

All processing in browser.

</details>

<details>
<summary>**Maximum length?**</summary>

NTFS / APFS: 255 chars. ext4: 255 bytes. URL: 2,000 in practice. Generator defaults to 100 — covers all platforms with margin.

</details>

## Tips

- Always transliterate to ASCII for maximum portability — UTF-8 works in modern systems but breaks in legacy ones.
- Use date prefix (YYYY-MM-DD-) for sortability — alphabetical sort gives chronological order.
- Strip Windows reserved names defensively — even on macOS / Linux, the file might end up on a Windows backup drive.
- Keep extensions intact — strip-and-rename without preserving .pdf breaks every consumer.
