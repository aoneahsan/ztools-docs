# AI Brand Visibility

Enter a brand name and check how available AI sources describe it. Connected providers answer through your own keys for OpenAI, Gemini, Claude, or Perplexity. If you're signed in without an OpenAI key, ZTools also sends a shared AI request from its server to a provider selected with FilesHub credentials. That shared request uses your daily AI allowance; own-key requests may be billed by those providers. Your monthly Brand Visibility limit also applies. Read each answer as a point-in-time result. It may be wrong, and a source link appears only if the provider returns one.

## Use cases

### Check a first impression

Enter your brand name and read how an available AI source describes it. Check any product or pricing claim against your current site before you reuse the answer.

### Compare connected sources

If you've added provider keys, run the same built-in brand question across those providers and compare the answers that succeed.

### Recheck later

Run a later check with the same brand name and compare the text yourself. The tool doesn't date or save snapshots or calculate a trend.

## How it works

1. **Enter your brand** — Type the brand name you want to check. The tool asks what the brand does, who its competitors are, and what its reputation is.
2. **Connect providers or sign in** — The check runs connected providers automatically. If you're signed in without an OpenAI key, it also runs a shared AI request. Own-key requests may incur provider charges.
3. **Run the check** — Available sources answer in parallel. One monthly Brand Visibility unit is kept if any source returns an answer. Shared AI requests also use the daily allowance.
4. **Compare answers** — After the separate shared-result card ships, read each answer under the route that actually returned it. Source links appear only when supplied.
5. **Check before acting** — Treat each answer as a snapshot. Verify claims against current source pages before changing your own content.

## Frequently asked questions

<details>
<summary>**Is AI Brand Visibility free, and what does it cost?**</summary>

The Free plan has a monthly Brand Visibility limit. Paid Growth plans may raise it. A shared check also uses the daily AI allowance shown in ZTools; requests made with your connected provider keys may be billed by those providers. Review the keys you've connected before running.

</details>

<details>
<summary>**Do I need my own API key?**</summary>

If you're signed in without an OpenAI key, ZTools can use the shared AI allowance. To compare named providers, add their keys in Settings. The current check automatically runs each connected provider; there is no source selector.

</details>

<details>
<summary>**Are the results accurate and permanent?**</summary>

No. An AI answer may be wrong or change later. The screen does not save or date its answers, so keep your own record if you need to compare runs.

</details>

<details>
<summary>**Which AI engines does it query?**</summary>

The own-key providers are OpenAI, Gemini, Claude, and Perplexity, according to the keys you connect. ZTools also runs one FilesHub-routed shared request when you're signed in without an OpenAI key. Its actual provider may differ from the named own-key providers. A result appears only when that request succeeds.

</details>

<details>
<summary>**Can I compare competitors?**</summary>

The current check asks about the entered brand and its main competitors in one fixed prompt. It has no separate competitor-benchmark control or scored comparison.

</details>

<details>
<summary>**Will every answer include sources or a sentiment score?**</summary>

No. A source link appears only when a provider returns it. The current tool compares the answer text and counts mentions of the brand name; it doesn't calculate a sentiment score. Check source pages yourself before using an answer in a report.

</details>

<details>
<summary>**Does my brand data stay private?**</summary>

Your brand prompt goes to each provider whose key you've connected. If you're signed in without an OpenAI key, ZTools also sends one shared request from its server to the selected AI provider; FilesHub supplies connection credentials. Own-key requests go to those providers from your browser. Avoid entering private brand information you don't want those services to process.

</details>

## Tips

- Check each factual claim in an answer against current primary sources.
- Compare only the providers that returned an answer; an unavailable provider is not a negative result.
- Open a source link when one is returned and verify what it actually supports.
- Recheck later if the subject changes; the screen doesn't date or save results.
- Review own-key provider charges before connecting multiple provider keys.
