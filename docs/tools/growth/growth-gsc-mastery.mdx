# GSC Mastery

Connect a Search Console property and choose one of three preset reports: top queries, page performance, or country breakdown. Each reads a fixed window from the last 28 days. ZTools sends the returned rows to your chosen AI route for a written explanation. Shared AI uses the daily allowance; your provider may charge for own-key requests. Your plan's monthly GSC Mastery limit also applies. Check flagged queries and pages in Search Console before changing your site.

GSC Mastery is part of Growth Suite. Sign in to see its current allowance and any connection or provider key it needs. Limits vary by plan; a limited Free plan is available.
:::

## Use cases

### Review top queries

Run the top-queries report for a connected property and check which returned terms deserve closer reading in Search Console.

### Review page performance

Run the page-performance report to see returned page rows and the AI's suggestions. Verify each URL and metric before changing a title.

### Review countries

Run the country-breakdown report to see the returned geographic rows. The report alone cannot justify a localization investment.

## How it works

1. **Connect Search Console** — Connect a Google account with access to the Search Console property you want to read.
2. **Choose an AI route** — Choose shared AI while signed in or a provider key you've connected. Shared requests use the daily allowance; own-key calls may be billed by your provider.
3. **Choose a preset** — Choose top queries, page performance, or country breakdown. Each uses the app's fixed recent date window.
4. **Read the explanation** — The selected AI route reads the returned Search Console rows and writes an explanation. It does not run a position-drop or keyword-gap preset.
5. **Verify, then act** — Check each query, page, and conclusion in Search Console. Copy the text yourself if you need a record; the screen does not save runs.

## Frequently asked questions

<details>
<summary>**Is GSC Mastery free, or what does it cost?**</summary>

You can run GSC Mastery within the Free plan's monthly analysis limit. Paid Growth plans may raise it. Shared AI also uses the daily allowance; your own AI provider may bill requests made with your key.

</details>

<details>
<summary>**Do I need my own API keys?**</summary>

Connect the Google account that can read your Search Console property. For the explanation, use shared AI if allowance is available or connect your own AI provider key. A separate OpenAI or Anthropic key isn't required for the shared option.

</details>

<details>
<summary>**Can I trust the insights without checking the raw data?**</summary>

Treat the explanation as a lead. Verify returned queries, pages, and figures in Search Console before acting.

</details>

<details>
<summary>**Why might the tool miss some of my queries?**</summary>

The tool can read only rows returned for its three bounded presets. Search Console may omit some data; an absent query in this result is not proof of no traffic.

</details>

<details>
<summary>**What data does it access, and where does it go?**</summary>

The tool reads the selected Search Console rows. For a shared request, ZTools sends relevant rows directly from its server to the selected AI provider using credentials from FilesHub; an own-key request goes to the provider you choose. The tool doesn't change your Search Console property.

</details>

<details>
<summary>**Which analyses are included?**</summary>

The current presets are top queries, page performance, and country breakdown for a fixed recent window. Keyword-gap, position-drop, and rising-query reports are not present.

</details>

<details>
<summary>**Does it guarantee better rankings?**</summary>

No. The explanation can suggest questions to investigate, but it cannot guarantee search outcomes. Check the returned data in Search Console before making a change.

</details>

## Tips

- Compare the returned query or page in Search Console before changing content.
- Use the country report to find questions for further research, not proof of a market opportunity.
- With your own key, review provider charges; shared AI uses the daily allowance.
- Copy an explanation yourself if you need a record; the tool doesn't save a report series.
- Keep in mind that each preset reads a bounded row set.
- Use Search Console itself for date comparisons and query filters that the current screen does not offer.
