## Use cases

### Check a page before publishing

Before publishing a reachable preview page, run Website Audit to check its title, description, headings, canonical tag, image alt text, and internal links. You can paste its HTML if the preview URL cannot be fetched. Fix confirmed issues, then run it again after publication.

### Hand a client a clear before/after

Run an audit of a public client page and share the three directional scores with the issues the scanner found. Check each issue on the live page before turning it into a work item.

### Check a page after a site change

After a site change, scan a public page again or paste its HTML to spot changed metadata or headings. Compare the findings with the page itself before attributing a score change to the release.

## How it works

1. **Enter a URL or paste HTML** — Enter a public URL for ZTools to fetch, or paste HTML for the scanner to analyze without fetching the page.
2. **Review the SEO score** — The SEO score checks the title, meta description, headings, canonical tag, Open Graph metadata, image alt text, and internal links it can find in the supplied HTML. It does not inspect robots directives.
3. **Review the AEO score** — The AEO score checks detected FAQ or article schema, question-style headings, and text structure. It does not test whether an assistant will quote the page.
4. **Review the GEO score** — The GEO score checks detectable authorship, citations, date metadata, schema, and semantic markup. It does not measure actual appearances in AI answers.
5. **Check the suggested fixes** — Review the issues and suggestions under each score, then confirm them on the page before changing it. The scores do not predict ranking changes.

<details>
<summary>**What is the difference between SEO, AEO, and GEO?**</summary>

SEO checks on-page search signals. AEO checks answer-oriented structure, such as question headings and schema. GEO checks other readable signals, including authorship, dates, and cited sources. These labels describe the scanner's heuristics, not measured search-engine outcomes.

</details>

<details>
<summary>**Can it audit a page behind login or on staging?**</summary>

URL mode needs a page the ZTools proxy can reach without signing in. If a preview is private, use Paste HTML mode with markup you are allowed to provide; it analyzes that text without fetching the page.

</details>

No. The audit reads the URL or HTML you provide and cannot edit your site or guarantee search rankings. Its findings are checks to verify, not a priority order proven by impact.

## Tips

- Put a clear answer near the question it addresses, then check whether the scan recognizes the structure.
- Add useful questions and answers for readers when the page calls for them; don't add FAQ markup only to raise a score.
- Re-run the audit after a site change and check the current page against its findings.
- Confirm each suggested fix on the live page before prioritizing it.
- Use other sources for backlinks and actual search performance; this scan reads one page.
