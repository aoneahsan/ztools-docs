# PDF Page Reorder

PDF page reordering rearranges pages within a single document — page 5 becomes page 1, page 1 becomes page 8, and so on. The simplest case of PDF organisation. Useful after a merge that produced wrong order, when fixing a mis-scanned document, or when restructuring a presentation. The ZTools PDF Page Reorder tool is a focused single-purpose UI: drag pages in the grid, see the new order live, save.

<ToolCTA toolId="pdf-page-reorder" toolName="PDF Page Reorder" />

## Use cases

### Fix order after a merge

Merged 3 PDFs but they came out alphabetical instead of chronological. Drag to fix.

### Move appendix to the end

Imported document has appendix mid-stream; drag to position 99.

### Preview different orderings

Comparing whether intro should be page 1 or 3. Drag, look, decide.

## How it works

1. **Drop PDF** — Pages render as thumbnails.
2. **Drag-drop** — Move thumbnails to new positions. Auto-save snapshot of changes.
3. **Save** — New PDF with the new page sequence.

## Examples

**Input:** 10-page PDF, swap pages 3 and 7

**Output:** New PDF: 1, 2, 7, 4, 5, 6, 3, 8, 9, 10.

## Tips

- For complex restructuring (delete + reorder + rotate), use the Organize PDF tool. Simple reorder is faster here.
- After reorder, re-check internal references — page-X references in the body don't auto-update.
