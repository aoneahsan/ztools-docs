# Excel to PDF Converter

An Excel-to-PDF converter renders a spreadsheet as a PDF that looks the same for everyone and cannot be edited by accident. The ZTools Excel to PDF tool has two modes. On our server, LibreOffice opens the XLSX, XLS or ODS workbook (up to 30 MB) and prints it using the workbook's own page setup: cell formatting, borders, fonts, charts, print areas and page breaks; macros never run, and the server deletes your file right after processing. It needs a free Google sign-in. On this device, you pick one sheet of an XLSX or CSV file and it becomes a clean table PDF with the page size and orientation you choose; nothing is uploaded, but cell styling and charts are not carried over.

## Use cases

### Sharing a financial report without recipients editing the numbers

PDF locks the values; XLSX invites accidental edits. Convert before sending so the numbers everyone sees are the numbers you signed off on.

### Printing complex Excel layouts with consistent page breaks

The server mode prints with the workbook's own print areas and page setup, so the PDF pages match what you set up in Excel.

### Submitting spreadsheet outputs to systems that only accept PDF

Government portals, audit submissions, and many archival systems require PDF. Convert each report once, save the PDF as the official record alongside the XLSX source.

### Generating PDF invoices from an Excel template

Fill in the invoice template each month, convert to PDF, email. Recipients can't accidentally change the totals; you keep the editable XLSX as your source of truth.

## How it works

1. **Add your spreadsheet** — XLSX, XLS or ODS up to 30 MB for the server mode; XLSX or CSV for the on-device mode. Password-protected files must be unlocked first.
2. **Choose where to convert** — "On our server" keeps the formatting, charts and page setup and needs a free Google sign-in. "On this device" builds a table PDF in your browser with no upload.
3. **Set the page (on this device)** — Pick the sheet, the page size and the orientation. The server mode uses the page setup saved in the workbook.
4. **Convert** — The server prints every sheet that has content with LibreOffice; the on-device mode lays out the chosen sheet as a table.
5. **Download and check** — Open the PDF and check the page breaks and chart placement before sending it.

## Frequently asked questions

<details>
<summary>**Are charts preserved?**</summary>

In the server mode, yes — charts are drawn into the PDF by LibreOffice. The on-device mode exports cell values only.

</details>

<details>
<summary>**Will my XLSX be uploaded?**</summary>

Only in the "On our server" mode, which sends it over HTTPS to our own processing server; the server deletes the workbook and the PDF right after processing and never runs its macros. The "On this device" mode never uploads anything.

</details>

<details>
<summary>**Will all sheets be in the PDF?**</summary>

On our server, the sheets that have content are printed in order, following each sheet's print area. On this device, you choose one sheet per PDF.

</details>

<details>
<summary>**Are formulas preserved?**</summary>

PDFs hold values, not formulas. The PDF shows the calculated output of every formula at the moment of conversion.

</details>

<details>
<summary>**Are conditional-formatting colors preserved?**</summary>

In the server mode, yes — the cell colours at conversion time are baked into the PDF.

</details>

<details>
<summary>**Can I convert `.xls` (old Excel format)?**</summary>

Yes, in the server mode. The on-device mode reads .xlsx and .csv only.

</details>

## Tips

- Set your print area in Excel before converting — the server mode respects it.
- For multi-sheet workbooks, use the print-preview pane in Excel first to verify each sheet's layout.
- For very wide sheets, set scaling to "fit all columns on one page" in Excel before converting.
- After conversion, run PDF Compressor if the output is large.
