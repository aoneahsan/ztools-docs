# Word to PDF Converter

A Word-to-PDF converter takes a Microsoft Word document and renders it as a standard PDF that looks the same on every device. The ZTools Word to PDF tool has two modes. On our server, LibreOffice opens the DOCX, DOC, ODT or RTF (up to 30 MB) and prints it to PDF with the original layout: fonts, page breaks, tables, headers and footers, images and links; macros never run, and the server deletes your file right after processing. It needs a free Google sign-in. On this device, the DOCX is read in your browser and rebuilt as a simpler PDF that keeps headings, bold and italic text, lists and images but simplifies complex layout; nothing is uploaded. Neither mode adds a watermark.

## Use cases

### Producing a final PDF from a draft contract or report

PDF is the universal "no further edits" format. Convert your final DOCX with the server mode, attach it to an email or upload it to your DMS, and the recipient sees the layout you intended — fonts, page breaks and all.

### Submitting a resume as PDF (the standard for ATS systems)

Recruiters and applicant-tracking systems prefer PDF over DOCX (consistent rendering, no accidental edits). Convert your DOCX resume before submitting to job boards or HR portals.

### Converting an old .doc file

Legacy Word files from years ago still open in the server mode, which accepts .doc as well as .docx, so there is no need to re-save them first.

### Generating PDFs for archival or compliance reasons

Some industries (legal, finance, healthcare) keep records as PDF. Convert the DOCX output of a template to PDF for a fixed record.

## How it works

1. **Add your Word file** — DOCX, DOC, ODT or RTF up to 30 MB for the server mode; DOCX for the on-device mode. Password-protected files must be unlocked first.
2. **Choose where to convert** — "On our server" keeps the exact layout and needs a free Google sign-in. "On this device" converts in your browser with no upload, with a simplified layout.
3. **Set the page (on this device)** — Pick the page size (A4, Letter and more) and orientation. The server mode uses the page setup saved in the document.
4. **Convert** — The server prints the document with LibreOffice; the on-device mode maps headings, runs, lists and images into a PDF.
5. **Download and check** — Open the PDF in any reader and check the page breaks before sending it.

## Frequently asked questions

<details>
<summary>**Will fonts be preserved?**</summary>

On our server, documents in Arial, Times New Roman, Courier New, Calibri or Cambria keep their line and page breaks, because the server has metric-compatible versions of those fonts. Other fonts are replaced by a similar one unless they are embedded in the DOCX (Word: File → Options → Save → Embed fonts).

</details>

<details>
<summary>**Are hyperlinks clickable in the resulting PDF?**</summary>

In the server mode, yes — links in the document become PDF links.

</details>

<details>
<summary>**Will my DOCX be uploaded?**</summary>

Only in the "On our server" mode, which sends it over HTTPS to our own processing server; the server deletes the document and the PDF right after processing and never runs its macros. The "On this device" mode never uploads anything.

</details>

<details>
<summary>**Are tables preserved?**</summary>

On our server, yes — row and column structure, borders and cell alignment. On this device, tables are simplified.

</details>

<details>
<summary>**Are page breaks honored?**</summary>

On our server, yes — manual page breaks and section breaks produce the same PDF page boundaries as in Word.

</details>

<details>
<summary>**Can I convert a `.doc` file (older Word format)?**</summary>

Yes, in the server mode. The on-device mode reads .docx only.

</details>

## Tips

- Embed fonts in your DOCX (File → Options → Save → "Embed fonts in the file") for guaranteed font fidelity in the PDF.
- Use the server mode whenever the layout matters: contracts, resumes, forms.
- For multi-section documents (different headers per section), use Word's section breaks before converting.
- After conversion, run PDF Compressor if the output is image-heavy.
