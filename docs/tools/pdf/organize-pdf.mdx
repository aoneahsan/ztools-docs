# Organize PDF

Organising a PDF means manipulating its page-level structure — reordering pages, deleting unwanted ones, rotating individual pages, inserting pages from another PDF, splitting into multiple PDFs. Common after merging documents from multiple sources or cleaning up a scan with extra pages. The ZTools Organize PDF tool offers a visual page-grid UI: drag to reorder, click to delete, rotate per-page, drop another PDF to insert at any position. All operations local; no upload.

<ToolCTA toolId="organize-pdf" toolName="Organize PDF" />

## Use cases

### Clean up a scan with blank pages

Auto-feeder scanned 30 pages but 5 were blank. Delete the blanks, save the cleaned version.

### Reorder a presentation

Slides 5 and 6 should swap. Drag in the page-grid; save.

### Rotate sideways pages

Mixed-orientation scan; some pages came in landscape. Rotate per-page to portrait.

### Combine multiple PDFs into one structured doc

Drop multiple PDFs; arrange pages from each into a final order; save as single PDF.

## How it works

1. **Drop PDF** — Pages render as thumbnails in a grid.
2. **Manipulate** — Drag to reorder, click X to delete, rotate buttons per page. Drop another PDF to append or insert.
3. **Preview changes** — Live preview of final order before saving.
4. **Save** — New PDF with the chosen page sequence. Original untouched.

## Frequently asked questions

<details>
<summary>**Lossy or lossless?**</summary>

Lossless — page content is unchanged, only reorganised. File size approximately the same as the source.

</details>

<details>
<summary>**Can it preserve bookmarks / TOC?**</summary>

Bookmarks pointing to deleted pages get dropped. Surviving bookmarks are remapped to the new page numbers.

</details>

<details>
<summary>**Maximum file size?**</summary>

Browser memory. Up to ~200 MB / few hundred pages comfortable.

</details>

<details>
<summary>**Privacy?**</summary>

All in browser.

</details>

## Tips

- For large reorganisation, use the bulk-select feature — drag a box to select multiple pages.
- Always preview before saving — catches mis-orderings.
- For repeated reorganisations of the same PDF (e.g. weekly report), save your action sequence as a preset (where supported).
- For password-protected PDFs, decrypt first; tool can't modify locked PDFs.
