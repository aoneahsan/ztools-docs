# Welcome to ZTools Documentation

**ZTools** is a free collection of **570+ developer & creator tools** — JSON formatters, password generators, image compressors, regex testers, QR generators, PDF tools, and more. The vast majority run entirely in your browser: no signup, no upload, no data leaves your device. (A small paid Growth Suite adds AI-assisted SEO tools that need a sign-in and your own API key.)

This site documents how each tool works — with real use cases, worked examples, FAQs, and tips you won't find on the app pages alone.

## What you can do here

- **Browse all tools** — see the [full catalog](/docs/tools) organized by category.
- **Read in-depth guides** — task-oriented [how-to guides](/docs/guides) covering common workflows.
- **Reference release notes** — the [blog](/blog) tracks new tools, improvements, and the dev journal.
- **Open the app** — every documented tool links directly to [ztools.zaions.com](https://ztools.zaions.com).

## Why ZTools exists

Most "free online tools" upload your data to a server, run paid analytics on you, or hide the actual product behind ads. ZTools is the opposite: open-source documentation, browser-only processing, no tracking that you can't disable, no upsell, no email gate.

The full source code for the documentation site you're reading is on [GitHub](https://github.com/aoneahsan/ztools-docs) — fork it, audit it, contribute fixes.

## Privacy & honesty

ZTools tools are browser-only by design. The [privacy policy](https://ztools.zaions.com/privacy) details exactly what happens with your input data (almost always: nothing — it stays on your device).

When a tool has limits, this documentation says so explicitly. We don't claim "all-in-one solution" when a tool only handles 80% of cases. Honest framing earns more trust than marketing copy.
