# Welcome to ZTools Documentation

A different site for every small job makes the next step hard to find. ZTools brings useful digital tools into one place: JSON formatters, password generators, QR code generators, image compressors, and more. One task. Then another.

<a id="where-can-i-find-a-tool-or-guide"></a>
## 🧰 Where can I find a tool or guide?&nbsp;[#](#where-can-i-find-a-tool-or-guide)

Start with the catalog or follow a guide for a longer task. Tool pages include examples and usage notes.

| Section | What you'll find |
|---|---|
| [All tools](/docs/tools) | Tool pages grouped by category |
| [Guides](/docs/guides) | Instructions for common tasks |
| [Blog](/blog) | Release notes and tool updates |
| [Changelog](/docs/changelog) | Version history |

<a id="how-does-a-tool-process-my-work"></a>
## 🔒 How does a tool process my work?&nbsp;[#](#how-does-a-tool-process-my-work)

Many tasks run in your browser. AI and some file tasks send input to a server or provider. Some actions require an account or have plan limits. Read the [ZTools privacy policy](https://ztools.zaions.com/privacy-policy) for data handling details before submitting sensitive input.

<a id="how-do-i-start-a-task"></a>
## ▶️ How do I start a task?&nbsp;[#](#how-do-i-start-a-task)

Choose a tool in the [catalog](/docs/tools), then [open ZTools](https://ztools.zaions.com) to use it.
