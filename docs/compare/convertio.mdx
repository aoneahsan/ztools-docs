# Moving from Convertio to ZTools

Convertio sells server time by the credit and states 300+ formats. ZTools has converters for the common formats, most of them running in your browser with no credit to spend. It does not try to match that format list.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://convertio.co" target="_blank" rel="noopener noreferrer nofollow">Convertio's own site</a>, since prices move.

## Which page does which job

| On Convertio | In ZTools |
|---|---|
| Images | [Image Converter](/docs/tools/image/universal-image-converter) |
| Many images at once | [Batch image converter](/docs/tools/image/image-format-batch-converter) |
| HEIC to JPG | [HEIC to JPG](/docs/tools/conversion/heic-to-jpg) |
| Audio | [Audio Format Converter](/docs/tools/media/audio-format-converter) |
| Word to PDF | [Word to PDF](/docs/tools/pdf/word-to-pdf) |
| CSV and JSON | [CSV and JSON](/docs/tools/conversion/csv-json) |

## Steps

1. Note the from and to formats you actually use on Convertio.
2. Look for each in the table above and the [conversion tools](/docs/tools/conversion).
3. Convert one real file and open the result in the program you use it in.
4. If a format is missing here, keep Convertio for that one job.

## What stays with Convertio

- Unusual formats: Convertio states far more of them.
- Very large files. A browser tool works within your device; Convertio plans buy 1 GB to 10 GB on its servers.
