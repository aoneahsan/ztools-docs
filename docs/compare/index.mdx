# Moving to ZTools from another tool site

None of these sites hands anything over: no accounts, recipes or stored files carry across. Moving means opening your next job in ZTools, so each guide starts with the page for each job, then says what you would be giving up.

Facts in every guide link to the page we read them on, last checked Nov 7, 2026. The same facts side by side are on [Other tool sites](https://ztools.zaions.com/alternatives).

## PDF work

- [iLovePDF](/docs/compare/ilovepdf): A PDF tool site with web, mobile and desktop apps and a paid Premium plan.
- [Smallpdf](/docs/compare/smallpdf): A PDF tool site from Switzerland with a mobile app, a Chrome extension and Pro, Team and Business plans.
- [PDF24 Tools](/docs/compare/pdf24): A free, ad-supported PDF tool site from a German company, with a Chrome extension and a Windows desktop app that keeps files local.

## File conversion

- [Convertio](/docs/compare/convertio): A file converter for 300+ formats that runs on their servers and sells monthly credit plans.
- [CloudConvert](/docs/compare/cloudconvert): A server-side file conversion service and API sold by conversion credits, with a small free daily allowance.
- [Zamzar](/docs/compare/zamzar): An online file converter with free use capped at two files a day and three monthly plans for bigger files and more volume.

## Developer and data tools

- [CyberChef](/docs/compare/cyberchef): An open-source web app for encoding, encryption, hashing and data operations that chains steps into a recipe, all in the browser.
- [IT Tools](/docs/compare/it-tools): An open-source collection of developer utilities you can use online or self-host with Docker.

## Several kinds of job

- [TinyWow](/docs/compare/tinywow): A free PDF, image, video, file and AI writing tool site with no sign-up and paid Unlimited plans per category.
- [123apps](/docs/compare/123apps): A set of 51 free web apps for video, audio and PDF with one Premium subscription that removes ads.
- [Online Tools (Browserling)](/docs/compare/online-tools): A large collection of image, text and data utilities from Browserling that run in your browser, with a limited free tier and paid passes.
- [10015 Tools](/docs/compare/10015-tools): A free all-in-one toolbox for text, image, PDF, social media, coding, CSS and color jobs, with Chrome and Firefox extensions.
