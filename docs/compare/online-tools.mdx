# Moving from Online Tools (Browserling) to ZTools

Online Tools runs in your browser too, and its worked examples are good. The difference is the free plan: it states 5 uses a day, ads and a wait before download. Its paid plans also let you combine tools.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://onlinetools.com" target="_blank" rel="noopener noreferrer nofollow">Online Tools (Browserling)'s own site</a>, since prices move.

## Which page does which job

| On Online Tools (Browserling) | In ZTools |
|---|---|
| Resize images | [Image Resizer](/docs/tools/image/image-resizer) |
| Crop images | [Image Cropper](/docs/tools/image/image-cropper) |
| Count words | [Word Counter](/docs/tools/text/word-counter) |
| Remove duplicates | [Duplicate Remover](/docs/tools/text/duplicate-remover) |
| Format JSON | [JSON Formatter](/docs/tools/data/json-formatter) |
| Sort a list | [List Sorter](/docs/tools/data/list-sorter) |

## Steps

1. Pick the utilities you hit the daily limit on, and find them in the [tool index](/docs/tools).
2. Run a sample through both and compare the output before relying on it.
3. If you pay for a pass, finish the paid period while you check.

## What stays with Online Tools (Browserling)

- Combining tools into one chain is part of its Premium plan.
- Its pages carry worked examples for each tool.
