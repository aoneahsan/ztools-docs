# Moving from PDF24 Tools to ZTools

PDF24 is free with no artificial limits and pays for itself with ads. Its online tools process files on its servers; many ZTools PDF tools stay in your browser. That and the non-PDF jobs are the case for moving.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://tools.pdf24.org/en/" target="_blank" rel="noopener noreferrer nofollow">PDF24 Tools's own site</a>, since prices move.

## Which page does which job

| On PDF24 Tools | In ZTools |
|---|---|
| Merge | [Merge PDF](/docs/tools/pdf/merge-pdf) |
| Split | [Split PDF](/docs/tools/pdf/split-pdf) |
| Rotate | [Rotate PDF](/docs/tools/pdf/rotate-pdf) |
| Watermark | [Watermark PDF](/docs/tools/pdf/watermark-pdf) |
| Unlock | [Unlock PDF](/docs/tools/pdf/unlock-pdf) |
| Read text from scans | [PDF OCR](/docs/tools/pdf/pdf-ocr-text-extraction) |

## Steps

1. Pick one job you run often and repeat it on the matching page.
2. Check the tool page for how it handles your file. PDF OCR runs only on our server.
3. Add the [ZTools extension](/docs/guides/browser-extension) in place of the PDF24 one, or install the [Android app](/docs/guides/android-app).
4. Keep the PDF24 Creator if you need a Windows program that works offline.

## What stays with PDF24 Tools

- The PDF24 Creator desktop app keeps files on your PC. ZTools has no Windows program.
- PDF24 states no artificial limits, free of charge.
