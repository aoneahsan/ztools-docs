# Moving from CloudConvert to ZTools

If you call CloudConvert from code, ZTools does not replace it: there is no conversion API here. If you open it a few times a month to change a file format by hand, most of those jobs have a page here.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://cloudconvert.com" target="_blank" rel="noopener noreferrer nofollow">CloudConvert's own site</a>, since prices move.

## Which page does which job

| On CloudConvert | In ZTools |
|---|---|
| Images | [Image Converter](/docs/tools/image/universal-image-converter) |
| SVG to PNG | [SVG to PNG](/docs/tools/image/svg-png) |
| Audio | [Audio Format Converter](/docs/tools/media/audio-format-converter) |
| Word to PDF | [Word to PDF](/docs/tools/pdf/word-to-pdf) |
| Excel to PDF | [Excel to PDF](/docs/tools/pdf/excel-to-pdf) |
| Markdown to PDF | [Markdown to PDF](/docs/tools/conversion/markdown-to-pdf) |

## Steps

1. Check your CloudConvert history for the conversions you really run.
2. Run each on its page here. No account is needed for most.
3. Word and Excel to PDF run in your browser by default and offer a server mode; choose before you send a private file.
4. Leave your CloudConvert account in place if any script still calls it.

## What stays with CloudConvert

- The API, bulk conversions, custom fonts and team billing.
- Anything with a service level agreement behind it.
