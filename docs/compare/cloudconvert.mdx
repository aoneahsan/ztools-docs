# Moving from CloudConvert to ZTools

CloudConvert is a server-side conversion service and API, sold by conversion credits with a small free daily allowance. If you call it from code, run bulk conversions with a service level agreement, or need custom fonts and team billing, keep it: there is no conversion API here.

If you open it a few times a month to change a file format by hand, most of those jobs have a page here, free, in the browser, and without an account for most tools.

**Facts last checked Nov 7, 2026.** All of them come from <a href="https://cloudconvert.com" target="_blank" rel="noopener noreferrer nofollow">CloudConvert's site</a>, mostly its pricing page.

## Conversions you can do here

| On CloudConvert | In ZTools |
|---|---|
| Images | [Image Converter](/docs/tools/image/universal-image-converter) |
| SVG to PNG | [SVG to PNG](/docs/tools/image/svg-png) |
| Audio | [Audio Format Converter](/docs/tools/media/audio-format-converter) |
| Word to PDF | [Word to PDF](/docs/tools/pdf/word-to-pdf) |
| Excel to PDF | [Excel to PDF](/docs/tools/pdf/excel-to-pdf) |
| Markdown to PDF | [Markdown to PDF](/docs/tools/conversion/markdown-to-pdf) |

## From credits to pages

1. Look through your CloudConvert history for the conversions you really run.
2. Run each on its page here. Most need no account.
3. Word and Excel to PDF run in your browser by default and offer a server mode. Choose before you send a private file.
4. Keep the CloudConvert account while any script still calls it.

## Keep CloudConvert for

- The API, bulk conversions, custom fonts and team billing.
- Anything that needs a service level agreement behind it.
