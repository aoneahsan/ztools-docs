# Moving from Smallpdf to ZTools

Smallpdf states 30 tools, mostly PDF work. ZTools has pages for the common ones, then the jobs around them: images, text, code. There is no importer, so start with the job in front of you.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://smallpdf.com" target="_blank" rel="noopener noreferrer nofollow">Smallpdf's own site</a>, since prices move.

## Which page does which job

| On Smallpdf | In ZTools |
|---|---|
| Merge and split | [Merge PDF](/docs/tools/pdf/merge-pdf) |
| Reorder pages | [Reorder PDF pages](/docs/tools/pdf/pdf-page-reorder) |
| E-sign | [Sign PDF](/docs/tools/pdf/sign-pdf) |
| PDF to Word | [PDF to Word](/docs/tools/pdf/pdf-to-word) |
| Word to PDF | [Word to PDF](/docs/tools/pdf/word-to-pdf) |
| Fill a form | [PDF form filler](/docs/tools/pdf/pdf-form-filler) |

## Steps

1. Download what you keep in Smallpdf before a plan runs out.
2. Try [Sign PDF](/docs/tools/pdf/sign-pdf) on a test file. If your team needs e-signing and shared billing from one vendor, that is the reason to stay.
3. Swap the Smallpdf Chrome extension for the [ZTools extension](/docs/guides/browser-extension).
4. Word to PDF runs in your browser by default and offers a server mode. Check which one you picked before sending a private file.

## What stays with Smallpdf

- Team seats and billing from one vendor stay with Smallpdf.
- If you only touch PDFs, a larger catalogue gains you little.
