# Moving from Smallpdf to ZTools

Smallpdf is a PDF tool site from Switzerland with a mobile app, a Chrome extension and Pro, Team and Business plans. It states 30 tools, mostly PDF work. A team that wants a polished PDF suite with e-signing, a phone app and one bill from one vendor is well served there.

ZTools has pages for the common PDF jobs, then the image, text and code jobs around them. You can see the price before you start, and most tools run without a file upload. There is no importer, so start with the job in front of you.

**Facts last checked Nov 7, 2026.** Every fact below links back to <a href="https://smallpdf.com" target="_blank" rel="noopener noreferrer nofollow">Smallpdf's site</a> or its pricing page.

## Making the switch

1. Download what you keep in Smallpdf before your plan ends.
2. Try [Sign PDF](/docs/tools/pdf/sign-pdf) on a test file. If your team needs e-signing and shared billing from one vendor, that is the reason to stay.
3. Replace the Smallpdf Chrome extension with the [ZTools extension](/docs/guides/browser-extension).
4. Word to PDF runs in your browser by default and offers a server mode. Check which one you picked before you send a private file.

## When Smallpdf is still the answer

- Team seats and billing from one vendor.
- PDF-only work, where a larger catalogue gains you little.
