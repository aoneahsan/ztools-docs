# Moving from IT Tools to ZTools

IT Tools is open source and you can host it yourself. ZTools is a hosted service, so if running your own copy is the point, stay. If you want the same utilities next to image, PDF and everyday tools, here is where they are.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://it-tools.tech" target="_blank" rel="noopener noreferrer nofollow">IT Tools's own site</a>, since prices move.

## Which page does which job

| On IT Tools | In ZTools |
|---|---|
| Hash text | [Hash Generator](/docs/tools/encoding/hash-generator) |
| Bcrypt | [Bcrypt Generator](/docs/tools/developer/bcrypt-generator) |
| HMAC | [HMAC Generator](/docs/tools/developer/hmac-generator) |
| JWT | [JWT Decoder](/docs/tools/encoding/jwt-decoder) |
| JSON | [JSON Formatter](/docs/tools/data/json-formatter) |
| Cron | [Cron Generator](/docs/tools/developer/cron-job-generator) |

## Steps

1. Open the [developer tools](/docs/tools/developer) and the [encoding tools](/docs/tools/encoding) and bookmark the two or three you use.
2. Add the [browser extension](/docs/guides/browser-extension) if you want them one click from any tab.
3. If you run IT Tools on a server, you can leave it running. Nothing here depends on removing it.

## What stays with IT Tools

- Self-hosting. ZTools has no version you run on your own server.
- The open-source licence, if that matters to your team.
