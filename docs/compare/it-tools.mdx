# Moving from IT Tools to ZTools

IT Tools is an open-source collection of developer utilities that you can use online or host yourself with Docker. For a developer who wants hashes, tokens, converters and parsers with no account, and the option of running it on their own server, it is hard to beat.

ZTools is a hosted service, so if running your own copy is the point, stay. Move if you want the same kind of utilities next to image, PDF, SEO and everyday tools, on Android and as an extension.

**Facts last checked Nov 7, 2026.** Our source was <a href="https://it-tools.tech" target="_blank" rel="noopener noreferrer nofollow">IT Tools</a> and its GitHub repository.

## Setting it up

1. Bookmark the two or three you use from the [developer tools](/docs/tools/developer) and the [encoding tools](/docs/tools/encoding).
2. Add the [browser extension](/docs/guides/browser-extension) to have them one click from any tab, or the [Android app](/docs/guides/android-app) on your phone.
3. Leave your self-hosted IT Tools running if you have one. Nothing here needs it gone.
4. Before you paste a secret, read the tool page: it says whether the tool runs in your browser or on our server. [AI Background Remover](/docs/tools/image/background-remover), [Image to Text](/docs/tools/media/image-to-text-ocr) and [PDF OCR](/docs/tools/pdf/pdf-ocr-text-extraction) run only on our server.

## Reasons to stay on IT Tools

- Self-hosting. ZTools has no version you run on your own server.
- The open-source licence, if your team needs it.

## What IT Tools states

Its pages answer one question this table asks: it is free, and you can run it yourself with one docker command. They give no tool count and say nothing about uploads, accounts, ads, an Android app or an extension, so only that row is shown. For ZTools: the count is on the [tool index](/docs/tools); most tools need no sign-up, Growth Suite and Speak excepted; and there are no third-party ad networks, though the free plan promotes our own products.
