# Moving from TinyWow to ZTools

TinyWow and ZTools are both one site for many jobs. The difference to check first is where your file goes: TinyWow says files are processed on its side and deleted after an hour, and most ZTools tools stay in your browser.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://tinywow.com" target="_blank" rel="noopener noreferrer nofollow">TinyWow's own site</a>, since prices move.

## Which page does which job

| On TinyWow | In ZTools |
|---|---|
| PDF | [PDF tools](/docs/tools/pdf) |
| Resize an image | [Image Resizer](/docs/tools/image/image-resizer) |
| Compress a video | [Video Compressor](/docs/tools/media/video-compressor) |
| Video to GIF | [Video to GIF](/docs/tools/media/video-to-gif) |
| Rewrite text | [Article Rewriter](/docs/tools/text/article-rewriter) |

## Steps

1. List the three TinyWow tools you open most.
2. Find each in the [tool index](/docs/tools), or search from the [ZTools home page](https://ztools.zaions.com).
3. Read the processing line on each tool page. Video Compressor and Video to GIF offer a server mode; choose it only if your device struggles.
4. AI writing tools send your text to a provider. Read the [privacy page](/docs/privacy) before pasting anything private.

## What stays with TinyWow

- TinyWow states 50+ AI writing tools. If those are your main job, compare them first.
- No account is needed there or for most tools here, so there is nothing to close.
