# Moving from 10015 Tools to ZTools

10015 is a free, tidy toolbox. Move if you run out of tools there, or want an Android app. Otherwise, there is no hurry.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://10015.io" target="_blank" rel="noopener noreferrer nofollow">10015 Tools's own site</a>, since prices move.

## Which page does which job

| On 10015 Tools | In ZTools |
|---|---|
| Count text | [Word Counter](/docs/tools/text/word-counter) |
| Compress images | [Image Compressor](/docs/tools/image/image-compressor) |
| CSS grid | [CSS Grid Generator](/docs/tools/developer/css-grid-generator) |
| CSS flexbox | [CSS Flexbox Generator](/docs/tools/developer/css-flexbox-generator) |
| QR codes | [QR Generator](/docs/tools/encoding/qr-generator) |
| Merge PDFs | [Merge PDF](/docs/tools/pdf/merge-pdf) |

## Steps

1. Look in [Browse by category](/docs/guides/browse-by-category) for the job you came for.
2. Use the tool page as you would there. Most need no sign-up.
3. Swap the extension if you use one: the [ZTools extension](/docs/guides/browser-extension) is on the Chrome Web Store, and Firefox readers can use the web app.

## What stays with 10015 Tools

- If you use its social media or CSS generators, compare the one you use first.
- It states Chrome and Firefox extensions.
