# Moving from iLovePDF to ZTools

The common iLovePDF jobs have a ZTools page. There is no account or file import, so moving means opening the next job here instead. Keep iLovePDF for what ZTools has no answer to.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://www.ilovepdf.com" target="_blank" rel="noopener noreferrer nofollow">iLovePDF's own site</a>, since prices move.

## Which page does which job

| On iLovePDF | In ZTools |
|---|---|
| Merge files | [Merge PDF](/docs/tools/pdf/merge-pdf) |
| Split a file | [Split PDF](/docs/tools/pdf/split-pdf) |
| Sign a document | [Sign PDF](/docs/tools/pdf/sign-pdf) |
| Turn a PDF into Word | [PDF to Word](/docs/tools/pdf/pdf-to-word) |
| Add a password | [Protect PDF](/docs/tools/pdf/protect-pdf) |
| Make a file smaller | [Compress PDF](/docs/tools/pdf/compress-pdf-advanced) |

## Steps

1. Download anything you keep in iLovePDF. Nothing carries across.
2. Run your most common job on the matching page above with a file that does not matter, and read the result.
3. Sign a real document only after checking the signed copy opens the way you expect.
4. Install the [Android app](/docs/guides/android-app) if you used the iLovePDF phone app.

## What stays with iLovePDF

- iLovePDF has a desktop app. ZTools runs on the web, on Android and as a browser extension.
- Workflows and team seats are iLovePDF features built for offices that live in PDFs. If that is your day, stay.
