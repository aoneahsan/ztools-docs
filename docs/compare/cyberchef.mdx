# Moving from CyberChef to ZTools

CyberChef is an open-source web app for encoding, encryption, hashing and data operations. You chain steps into a recipe and it all runs in your browser. If ciphers and binary data are your daily work and you want saved recipes that run offline, keep CyberChef.

Privacy is not the reason to move: CyberChef does its work in your browser, and so do these ZTools pages. The reason is everything CyberChef was never meant for: images, PDFs, text and everyday jobs, each on a plain page of its own. Many people should keep both.

**Facts last checked Nov 7, 2026.** Each links to <a href="https://gchq.github.io/CyberChef/" target="_blank" rel="noopener noreferrer nofollow">CyberChef</a> or its GitHub repository.

## Rebuilding a recipe

1. Write down each operation in the saved recipes you use. Recipes do not import here.
2. Run them one page at a time, pasting each result into the next tool.
3. Put one known input through both and compare before you trust real data to it.
4. For the image and PDF jobs, start from the [tool index](/docs/tools).

## Keep CyberChef for

- Saved, chained recipes that run offline. That is the best thing about it.
- Running it locally. It can be downloaded from its own repository.

## What CyberChef's pages say

For ZTools: most tools need no sign-up (Growth Suite and Speak do), there are no third-party ad networks though the free plan promotes our own products, and there is an [Android app](/docs/guides/android-app) and a browser [extension](/docs/guides/browser-extension).
