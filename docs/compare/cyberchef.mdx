# Moving from CyberChef to ZTools

CyberChef does its work in your browser and so do these tools, so privacy is not the reason to move. The reason is everything outside encoding: images, PDFs, text. Many people should keep both.

**Facts last checked Nov 7, 2026.** Read them on <a href="https://gchq.github.io/CyberChef/" target="_blank" rel="noopener noreferrer nofollow">CyberChef's own site</a>, since prices move.

## Which page does which job

| On CyberChef | In ZTools |
|---|---|
| Base64 | [Base64](/docs/tools/conversion/base64) |
| Hashes | [Hash Generator](/docs/tools/encoding/hash-generator) |
| Decode a JWT | [JWT Decoder](/docs/tools/encoding/jwt-decoder) |
| URL encoding | [URL Encoder](/docs/tools/conversion/url-encoder) |
| Timestamps | [Unix Timestamp](/docs/tools/conversion/unix-timestamp) |
| Number bases | [Number Base](/docs/tools/conversion/number-base) |

## Steps

1. Write down the operations in any saved recipe you use. Recipes do not import here.
2. Run each operation on its own page, feeding one result into the next.
3. Check the output against CyberChef on one known input before you trust it for real data.
4. For the image and PDF jobs CyberChef was never meant for, start from the [tool index](/docs/tools).

## What stays with CyberChef

- Chained recipes you can save and run offline are the best thing about CyberChef. For those, stay.
- CyberChef can be downloaded and run locally from its own repository.
