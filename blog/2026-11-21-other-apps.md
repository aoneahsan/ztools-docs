# Your ZTools data, from a script, an assistant or your server

You keep a QR code on a printed menu, and the menu changes every season. Until now, pointing it somewhere new meant opening ZTools. Today a script, an assistant or your own server can do it for you.

<!-- truncate -->

## Three ways in

**Account**, then **Other apps**, has three new parts, on every plan.

- **Access keys** let a script or a spreadsheet use the [ZTools API](/docs/developers/api) as you: list your presets, save a run to history, point a QR code at a new page.
- **Assistants** connect Claude, ChatGPT, Claude Code or Cursor. Ask one to find a preset or tidy a collection. When it asks to remove something, ZTools asks you first, on a page of its own.
- **Webhooks** send a signed message to your server the moment something changes, such as a scan on one of your codes.

Each one gets only what you tick for it. Your teams, shared links and public content are read only from outside. Speak recordings and AI assistant conversations never leave ZTools.

## Two-step sign-in

**Account**, then **Security**, can now add a six-digit code from an authenticator app after Google. You get ten recovery codes, and you can let a browser you don't share skip the code for 7 days.

## Where to read more

[ZTools for developers](/docs/developers) has the details: what each tick reaches, every API address with an example, the webhook events and how to check their signatures, and what to do if you lose your phone.
