# Welcome to the ZTools Blog

This is the first post on the ZTools documentation blog. We'll use this space for:

- **Release notes** — what's new in each ZTools update
- **Tool spotlights** — deep-dives on individual tools and the problems they solve
- **Dev journal** — design decisions, technical tradeoffs, occasional mistakes

<!-- truncate -->

## What's shipped (May 2026)

- **520+ tools live** at [ztools.zaions.com](https://ztools.zaions.com) — all browser-only, no signup, no upload
- **First wave of docs** — top 20 highest-demand tools documented with use cases, examples, and FAQs ([browse them →](/docs/tools))
- **GitHub repo** for this docs site is open-source: [github.com/aoneahsan/ztools-docs](https://github.com/aoneahsan/ztools-docs)
- **Android app** shipped on Play Store; iOS pending Apple developer account approval

## What's next

- 15-20 tools per batch through batch 35+ until every documented tool from the app appears here
- Long-form how-to guides covering common workflows (compress images, format JSON, generate strong passwords)
- Algolia DocSearch integration for site-wide search

If there's a tool you'd like documented sooner, [open an issue on GitHub](https://github.com/aoneahsan/ztools-docs/issues) and we'll bump it up the queue.

— Ahsan
